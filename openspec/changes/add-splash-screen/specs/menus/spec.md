## ADDED Requirements

### Requirement: Splash Screen
The game SHALL show a Code 430 splash while it loads, crediting Godot Engine and OpenStreetMap and inviting players to help improve the game at its repository.

#### Scenario: Starting the game
- **WHEN** the player starts the game
- **THEN** the Code 430 card shows while it loads, with "Made with Godot Engine", "Map data © OpenStreetMap contributors", and "Help us improve it" with the repository link
